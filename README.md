# SoundCloud Friends Listening

Расширение Chrome (Manifest V3) + локальный FastAPI-сервер. Видишь, какой
трек сейчас слушают друзья прямо на странице SoundCloud, добавляешь по ник
нейму и подтверждаешь / отклоняешь входящие заявки в попапе расширения.

```
test/
├─ server/         FastAPI + SQLite сервер
└─ extension/      MV3-расширение Chrome
```

## Как это работает

- Контент-скрипт читает текущий трек из плеера SoundCloud и каждые ~12 секунд
  отправляет статус на локальный сервер.
- Сервер хранит пользователей, статусы и связи в `server/data.db` (SQLite).
- Расширение опрашивает «friends listening» feed и рисует виджет в правом
  верхнем углу страницы. Рядом с твоим аватаром в шапке SoundCloud появляется
  кнопка-«шестерёнка» — она открывает попап с настройками и друзьями.
- **Друзья только по двустороннему согласию.** Заявка отправляется → её надо
  принять или отклонить. Никто не добавляется автоматически из подписок.

## Запуск сервера (Linux / macOS)

```bash
cd server
chmod +x run.sh
./run.sh
```

`run.sh` сам создаёт `.venv`, ставит зависимости и стартует сервер на
`http://127.0.0.1:8765`.

Полный эквивалент вручную:

```bash
cd server
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
uvicorn main:app --host 127.0.0.1 --port 8765 --reload
```

## Запуск сервера (Windows)

```bat
cd server
run.bat
```

или вручную:

```bat
cd server
python -m venv .venv
.venv\Scripts\activate.bat
pip install --upgrade pip
pip install -r requirements.txt
uvicorn main:app --host 127.0.0.1 --port 8765 --reload
```

## Установка расширения

1. Открой `chrome://extensions/`.
2. Включи **«Режим разработчика»**.
3. Нажми **«Загрузить распакованное расширение»** → выбери папку `extension/`.
4. Кликни иконку расширения → вкладка **«Настройки»** → задай URL сервера
   (по умолчанию `http://127.0.0.1:8765`) → введи свой ник →
   **«Зарегистрировать»**.
5. Перезагрузи вкладку SoundCloud — справа в шапке появится кнопка-иконка
   расширения, а в правом верхнем углу страницы — виджет «FRIENDS LISTENING».

## Друзья и заявки

Во вкладке **«Добавить»** попапа введи ник пользователя или поищи —
отправляется заявка. У получателя в попапе во вкладке **«Заявки»** появятся
**Входящие** с кнопками *Принять* / *Отклонить*. Свои **Исходящие** можно
отменить. Только после взаимного согласия пользователь попадает в список
друзей и начинает видеть твой статус.

Иконка расширения подсвечивается оранжевым счётчиком, если есть входящие.

## API сервера (кратко)

| метод | путь                              | описание                                  |
|-------|-----------------------------------|-------------------------------------------|
| GET   | `/api/health`                     | health check                              |
| POST  | `/api/register`                   | `{username}` → `{user_id, username, token}` |
| GET   | `/api/me`                         | вернуть свой профиль                      |
| POST  | `/api/status`                     | пуш текущего трека                        |
| GET   | `/api/friends`                    | список друзей                             |
| POST  | `/api/friends/remove`             | удалить друга                             |
| GET   | `/api/friends/listening`          | кто из друзей сейчас слушает              |
| POST  | `/api/friends/request`            | отправить заявку по нику                  |
| GET   | `/api/friends/requests/incoming`  | входящие                                  |
| GET   | `/api/friends/requests/outgoing`  | исходящие                                 |
| POST  | `/api/friends/requests/accept`    | принять                                   |
| POST  | `/api/friends/requests/decline`   | отклонить                                 |
| POST  | `/api/friends/requests/cancel`    | отменить свою исходящую                   |
| GET   | `/api/users/search?q=...`         | поиск по нику                             |

Все запросы (кроме `/health` и `/register`) требуют заголовок
`X-User-Token: <ваш токен>` — расширение делает это автоматически.

## Где лежат данные

- Сервер: `server/data.db` (SQLite). Удалишь файл — всё обнулится.
- Расширение: `chrome.storage.local` (никнейм, токен, URL сервера).
