# Twitch Custom Themes

Расширение Chrome (Manifest V3) для полной кастомизации внешнего вида twitch.tv.

## Что умеет
- **26 предустановленных тем**: 10 тёмных + 10 светлых + 6 специальных (Glassmorphism, RGB Rainbow, Retro CRT, Anime Sakura, Vaporwave, Minimalist Mono).
- **Свой фон сайта и чата**: картинка или GIF с регулировкой размера, позиции, повтора, прозрачности и блюра. Можно подвинуть картинку, если не помещается.
- **Кастомизация чата**: фон сообщений, цвет/размер/шрифт текста, скругление углов, обводка текста, свечение.
- **Редактор тем с live‑превью**: каждое изменение мгновенно применяется к открытой вкладке Twitch. Не нравится — снимаешь галочку «Включить тему».
- **Сохранение, импорт и экспорт** кастомных тем в JSON.
- Работает локально, без серверов и аналитики.

## Установка (распакованное расширение)
1. Распакуй архив `twitch-themes-extension.zip` в любую папку.
2. Открой Chrome и перейди на `chrome://extensions/`.
3. Включи переключатель **«Режим разработчика»** в правом верхнем углу.
4. Нажми **«Загрузить распакованное расширение»** и выбери папку, в которую распаковал архив (там, где лежит `manifest.json`).
5. Готово — иконка появится в меню расширений. Закрепи её на панели для удобства.

## Использование
1. Открой [twitch.tv](https://www.twitch.tv) и оставь вкладку открытой.
2. Кликни по иконке расширения.
3. Во вкладке **«Темы»** нажми «Применить» на любой пресет — оформление поменяется сразу.
4. Во вкладке **«Редактор»** собери свою тему: цвета, фоны, картинки, гифки. Превью применяется сразу.
5. Нажми «Сохранить», чтобы тема появилась в **«Мои темы»**, или «Применить», чтобы сразу закрепить.
6. Через «⤓ Экспорт JSON» можно сохранить тему в файл и поделиться.

## Структура проекта
```
manifest.json
background/background.js     — service worker (инициализация storage)
content/                     — content script + базовый CSS
lib/theme-engine.js          — логика построения CSS из JSON-темы
themes/presets.js            — все 26 предустановленных тем
popup/                       — UI расширения (HTML/CSS/JS)
icons/                       — иконки 16/48/128 px
```

## Замечания
- Twitch иногда меняет вёрстку. Если что-то слетает — нажми «Применить» ещё раз или обнови страницу.
- Очень тяжёлые гифки могут немного тормозить чат — попробуй уменьшить размер или прозрачность.
- Все темы хранятся локально в `chrome.storage.local`.
